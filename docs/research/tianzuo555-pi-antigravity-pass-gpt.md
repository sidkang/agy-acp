## 2. What the extraction missed
All statements here describe checked adapter behavior, not live CLI validation.

- **Error classification:** only `SUCCESS`/`OK` terminal statuses normalize to success; absent/unknown/cancelled/timeout statuses normalize to error (`lib/reducer.ts:225-243`). Tool errors prefer top-level error then nested `tool_info.error`, collapse whitespace and truncate to 160 characters (`lib/reducer.ts:184-194`); caught permission-check errors get an allow-rule hint, whereas terminal-result errors do not pass through that hint (`src/provider.ts:306-314,861-867`).
- **Recovery limits:** only `AgyStallError` retries, at most twice with default 3-second backoff; persisted missing-conversation failures get a fresh-history fallback; retries/fallback share one logical deadline and receive remaining time (`src/runtime.ts:49-60,330-340,423-526`). Recovered-error success requires response text plus the specific `stream was interrupted` phrase, not arbitrary partial text (`src/provider.ts:851-870`; checked assertions in `test/provider.test.ts:1138-1159`, not run).
- **Watchdog distinctions:** default no-byte budget 120s, active-tool budget 300s; persistent mode can grant up to 12 tool-liveness graces and polls a transcript for a withheld final answer, producing a synthetic OK result when parked grace expires (`src/runtime.ts:384-387`; `lib/agy-driver.ts:241-247,617-642,667-683,691-711,736-816`). One-shot watchdog only uses inactivity and kills on expiry (`lib/agy-client.ts:225-247`).
- **Thinking surface:** reducer emits a thought activity only for DONE response steps with ≥64 thinking tokens; controller permits one thought summary per logical turn; elapsed seconds describe the response step, not a measured private reasoning interval (`lib/reducer.ts:15-21,208-219`; `lib/turn.ts:112-117`; `src/provider.ts:614-648`). Retry/stall notices also occupy thinking blocks, so this channel is partly diagnostics (`src/provider.ts:651-679`).
- **Effort/capability:** minimal/low→low, medium→medium, remaining explicit levels→high; discovered `-low/-medium/-high` models collapse into a base ID retaining supported/default effort; unsupported requested effort falls back, and models with no effort metadata get no `--effort` (`src/provider.ts:194-199,352-353`; `lib/models.ts:24-34,38-63,81-88`). Registration marks every model `reasoning: true` and text-only (`index.ts:143-152`).
- **Tool modes/security:** native default bridges only active `builtin:mcp` tools; Pi mode bridges active builtins/extensions/MCP, excluding hidden tools and replay wrapper (`lib/bridge.ts:59-77`). Both CLI argument builders unconditionally skip agy permissions (`lib/agy-client.ts:116-152`); native replay cards cannot prevent already-executed operations. Pi mode writes `tools: []`, `inheritCustomizations: false`, only its authenticated bridge, and refuses unprepared bridge/agent or conflicting custom-agent configuration (`lib/pi-tools-agent.ts:26-39`; `index.ts:365-413`).
- **Bridge isolation/protocol:** loopback ephemeral listener and header token are wired in production; private `.agents/mcp_config.json` is mode 0600 under a 0700 directory, passed via `--add-dir`; descriptor name is unique (`lib/bridge.ts:227-243,283-288`; `index.ts:345-350`; `lib/mcp-config.ts:7-33`; `lib/agy-client.ts:105-107`). This is POST JSON-RPC, not an SSE event stream: notifications return 202, replies JSON with a module-wide session ID, cancellation notifications are acknowledged without cancelling calls (`lib/bridge.ts:289-321,333-348,444`).
- **Bridge lifetime:** ordinary pending calls fail on timeout/no active turn/shutdown; tool result arrays preserve text/images. Dynamic skill handlers bypass the parked-call timeout path. Canonical tool-catalog digest and registration generation combine into a process revision; preparation is single-flight with partial-config cleanup (`lib/bridge.ts:80-83,192-212,247-260,400-440,446-464`; `lib/bridge-lifecycle.ts:61-109`).
- **Native channel/replay:** only narrowly recognized argument sets for `view_file`, `list_dir`, `grep_search`, `find_by_name` map to actual Pi re-execution; unrecognized arguments stay on wrapper (`lib/native-tools.ts:38-42,62-107`). Raw `call_mcp_tool` cards targeting this bridge are suppressed to avoid duplicates, and unfinished cards are closed before bridge handoff or replayed as incomplete before terminal result (`src/provider.ts:211-225,538-593,722-772,796-800`). Wrapper text returned to Pi is capped at 16,000 characters (`index.ts:691-702`).
- **Session/state lifetime:** controller survives toolUse handoffs, preserving usage claims, emitted-text deduplication and incomplete tools (`lib/turn.ts:16-37,49-76,84-134`). Executor queues turns and recycles on binary/version/revision, cwd, MCP directory, model, effort, agent, mode, catalog revision or conversation mismatch (`lib/agy-driver.ts:170-194,315-329,367-382`). Stale callbacks are fenced by generation/abort (`src/runtime.ts:189-194,389-410,535-554`).
- **Durability/branching:** Pi custom entries store session/cwd/model/conversation/tool mode/bridge identity, counters and usage; restore rejects wrong ownership, subsequent context changes, resets, and Pi-tools mode (`index.ts:287-319`; `lib/conversation-state.ts:146-170`). Startup also checks model and readable conversation DB; forks and changed private bridge identity rebuild bounded Pi history rather than blindly reusing mutable history (`index.ts:823-865`; `src/provider.ts:115-154`). Branch moves/provider switches invalidate continuity; explicit reset disables next-history replay (`index.ts:879-915`; `src/runtime.ts:581-592`).
- **Prompt/summary lifetime:** native mode relays only Pi documentation instructions; Pi-tools mode uses current Pi instructions, stripping only a validated Pi tool-inventory block (`index.ts:433-441`; `lib/prompt.ts:93-125`). Compaction/branch-summary prompts recognized by `<conversation>\n` use disposable runtimes, suppress normal tool UI and usage, then close/dispose without contaminating the user's native conversation (`src/provider.ts:172-181,290-303,324-339,432-435,722-743`).
- **Usage/window policy:** step usage is preferred over cumulative result usage; controller subtracts already-claimed cumulative usage and treats counter resets as new usage (`src/provider.ts:802-810`; `lib/turn.ts:119-134,205-213`). Registered context window is a deliberate 1,000,000-token Pi scheduling value, not a measured native model limit; pricing is a hard-coded display estimate, unknown models zero (`lib/models.ts:155-198`). Live model cache TTL is 24h versus fallback 5m (`lib/models.ts:201-213`).
- **Task ownership/safety:** orphan registry is process-global (`Symbol.for`) across extension copies, recording parent/leader/member start identities; a failed process scan neither verifies nor prunes records, and surviving groups need a matching recorded identity (`lib/agy-children.ts:119-134,237-295`). Per-task stop targets only proven log-holder PIDs, never advisory orphan/ambiguous associations (`lib/tasks.ts:780-820`); turn abort skips command-group reaping when the turn was positively classified as parked background work (`lib/agy-driver.ts:582-614`).
- **Platform handling:** managed binary name becomes `agy.exe` on Windows and lookup honors PATHEXT (`lib/agy-diagnostics.ts:168-170,196-200`). Windows kills use `taskkill /F /T /PID`; POSIX uses negative-PID process-group signals. Process-table probing and the extra command-group abort sweep are disabled on Windows, and artifact opening picks `open` on macOS, `xdg-open` everywhere else—no Windows opener branch (`lib/agy-children.ts:72-85,141-164,179-205`; `lib/agy-driver.ts:602-614`; `src/artifacts-ui.ts:109-114`). Do not infer equal platform coverage.
- **Packaging:** MIT, ESM, TypeScript extension loaded from `./index.ts`; publish allowlist contains source/index/lib/CHANGELOG, not test files or a compiled dist; dependencies are Effect 4.1.1, proper-lockfile 4.1.2, semver ^7.8.5, which ^7.0.0, with wildcard Pi peer versions (`package.json:5,16,26-49`). Typecheck/test commands are declared, but neither run here (`package.json:37-40`).

## 3. What our plugin should take from this one
Recommendations are inferences, not demonstrated fixes; costs are qualitative estimates.

1. **adopt** — Retain the binary-identity fence and consider strict, actionable preflight diagnostics: sibling checks override/PATH/managed candidates, prefers compatible stable versions, and returns the selected stat revision (`lib/agy-diagnostics.ts:178-207,354-423`). Prevents silent incompatible/stale binary reuse. Cost: bounded version probes (default 5s each, parallel) plus resolver/cache plumbing; ours already fences catalog refreshes (`ours:src/usage/catalog.ts:617-644`). Do not copy its `1.1.22` floor as an ACP guarantee; ours negotiates HTTP MCP capability (`ours:src/runtime/worker.ts:669-679`).
2. **adopt** — Keep fail-closed parked-tool ownership, not its numeric timeout: sibling resolves ordinary pending calls as errors on shutdown/no active turn/480s expiry (`lib/bridge.ts:247-260,416-440`). Prevents stranded HTTP requests and fabricated successful tool results. Cost: effectively none for the core rule—we already cancel/expire parked calls (`ours:src/mcp/broker.ts:271-283,446-469`); copying 480s would impose an unrelated Pi deadline on our caller-mediated HTTP tool loop (ours defaults to 15 minutes, `ours:src/mcp/broker.ts:56-58`).
3. **skip for us** — Synthetic thought summaries/empty pre-reserved slots (`src/provider.ts:606-679`) solve missing stream-json thought text and Pi content-index ordering. Our ACP path already consumes `agent_thought_chunk` with an exposure gate (`ours:src/runtime/worker.ts:893-901`). Cost: another synthetic content source, misleading elapsed-time semantics and extra HTTP/signature bookkeeping; it would replace richer evidence with a UI workaround.
4. **skip for us** — Native tool re-execution plus replay wrapper (`lib/native-tools.ts:62-107`; `src/provider.ts:490-535`; `index.ts:691-702`) provides Pi-native cards after agy operations. Prevents poor card rendering, not unauthorized native execution. Cost: duplicate reads and a second execution/UI model; our host is Anthropic-shaped HTTP, not Pi's tool renderer, so importing this would create misleading caller tool requests instead of fixing transport behavior.
5. **defer** — Transcript-based parked-final detection and ancestry-checked command-group sweeps (`lib/agy-driver.ts:582-614,667-711,736-816`) prevent stream-json turns waiting on already-backgrounded work and leaking command groups. Cost: CLI transcript-format coupling, process-table probes and platform-specific ownership bookkeeping. Our abort already sends ACP `session/cancel`, resolves broker calls and retires after a 1.5s settlement timeout (`ours:src/runtime/worker.ts:1618-1637`); require an ACP-specific reproduced leak/hang before copying stream-json recovery or filesystem probing.
