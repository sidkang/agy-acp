## 2. What the extraction missed
- **Engine choice/versions (code):** `AGY_ENGINE` overrides saved `engine`; fresh installs default ACP, but an existing config without `engine` preserves stream-json (`P:src/config.ts:277-286`). No automatic per-turn fallback is shown by the load-latched selection. Current ACP is **`agy acp`**, not the historical standalone RC01 binary; package gates ACP at **1.5.3**, stream-json at **1.1.22** (`P:src/agy-version.ts:18-28`; `P:extensions/index.ts:316-319`). Stream home isolation's reported verification ceiling is **1.5.8**, not a protocol guarantee (`P:src/agy-version.ts:22-28`).
- **Review-only safety (code vs report):** both engines refuse provider turns when `readOnly` or `mode === "plan"` is set (`P:src/provider.ts:1828-1856`), rather than claiming a permission mode makes execution read-only. The motivating stream-json write-through behavior is a dated author probe (`:1828-1835`); it does not prove every 1.5.8 ACP permission/agent configuration permits writes.
- **Carrier details (code):** SHA-256 body prefix caches write-once agent dirs; pid/time/random suffix avoids inter-process collisions; `.pid` and `agent.md` are 0600 in a 0700 dir (`P:src/sysprompt-agent.ts:84-123`). Stable conversation carrier is reused after the fresh-turn gate closes (`P:src/provider.ts:1552-1556`). Frontmatter quotes its colon-containing description, explicitly declares productive tools, `model: inherit`, `subagent: false`, `agents: []` (`P:src/sysprompt-agent.ts:51-75`). Missing `tools:` had removed write/edit/command tools; agent presence suppressing native subagents is a separately reported probe, not a proven effect of those two subagent keys (`:12-23`; `P:CHANGELOG.md:10`).
- **Error mapping (code):** JSON-RPC errors retain code/data (`P:src/acp/jsonrpc.ts:221-230`); `translateError` classifies **every -32000 passed to it** as auth, which is broader than proving an auth cause (`P:src/acp/connection.ts:580-594`). Prompt/load use raw requests (`:282-285,328-331`). Model/thought-level selection failure fails the turn, while mode-setting failure only logs (`P:src/acp/driver.ts:327-340`). Stop mapping: cancelled → OK+aborted; max_tokens → OK+error text; refusal/request-limit → ERROR; unknown → OK (`P:src/acp/events.ts:202-223`). The driver forwards that mapping (`P:src/acp/driver.ts:366-375`); provider only surfaces `outcome.error` on ERROR, so max_tokens is not forwarded as a distinct pi max-token terminal reason (`P:src/provider.ts:1761-1779`).
- **Thinking (code vs report):** ACP maps `agent_thought_chunk` text; stream-json exposes counts only (`P:src/acp/events.ts:49-55`; `P:src/driver-types.ts:60-62`). Sparse RC01 thought chunks on flash-low are reported, not evidence that all current models omit reasoning (`P:docs/ACP-PROTOCOL-REFERENCE.md:428-434`). A pi-native provider needs no Anthropic signature wire adaptation; that omission does not answer Magpie's HTTP-client contract.
- **Tool channel (code):** direct ACP HTTP header arrays and sanitized home are separate from stream config-object headers (`P:extensions/index.ts:342-353`; `P:src/mcp-registration.ts:83-93`). Real bridge calls become pi toolUse and park, while native ACP tool activity is display-only (`P:src/provider.ts:1222-1258,1321-1327`). MCP `rawInput.arguments` is unwrapped, `_meta.mcp.tool` preferred, content/diffs preferred over display-like rawOutput, and the legacy “approved but never executed” echo is dropped (`P:src/acp/events.ts:64-107,118-140`). Under deny policy with no human handler, choose a reject option or return cancelled; human decision budget is 480 s (`P:src/acp/connection.ts:78-81,369-391`).
- **Long tools (code/report):** bridge calls early-ack after 20 s, delegation-shaped names after 120 s, return `bridge_poll_result` handles, and extend escalated lifetime to 30 min (`P:src/provider.ts:448-488,923-947`). Settled-but-unpolled results can be re-delivered into the conversation (`:1400-1411,1696-1705`). The motivating ~180 s HTTP abandonment is a historical observation (`P:docs/ACP-PROTOCOL-REFERENCE.md:355`), not a verified 1.5.8 limit.
- **Usage (code):** parse exact turn totals separately from occupancy; optional synthetic fallback can be disabled (`P:src/acp/connection.ts:336-343,558-577`; `P:src/acp/driver.ts:802-835`). For pi's context gauge, retain billing fields but replace total with occupancy or `input + output + ceil(cacheRead/(toolBatches+1))` (`P:src/acp/driver.ts:839-856`); this is a client-derived gauge, not exact context usage. Mock-backed cancellation and usage assertions were inspected, not run (`P:tests/acp-driver.test.ts:387-403,828-859`).
- **Platforms (code):** spawn detached except Windows, hide Windows console; POSIX cancellation fallback targets group with TERM then KILL after 750 ms, Windows transport fallback calls child.kill, **not** installer-style taskkill tree cleanup (`P:src/acp/connection.ts:175-180,514-535`; `P:src/agy-install.ts:55-63`). PATH discovery targets `.exe` on Windows and accepts explicit separator-containing paths (`P:src/engine-picker.ts:88-132`); staging uses directory junction links (`P:src/acp/home.ts:12-14,70-89`). These are implementation branches, not proof of platform parity.
- **Setup/packaging (code/metadata):** optional confirmed installer offer uses PowerShell on Windows, bash/curl otherwise, then instructs manual CLI sign-in (`P:src/agy-install.ts:9-23`; `P:src/agy-setup.ts:33-57`). MIT ESM **pi extension**, source shipped via `extensions/` and `src/`, not an Anthropic HTTP service; npm allowlist excludes `docs/`, tests and probe scripts. Optional peer `@earendil-works/pi-coding-agent ^1.5.1`; runtime dependencies ask-shared `^0.1.6`, tui-dialogs `^0.1.3`, MCP SDK `^1.31.0` (`P:package.json:21,35-60`). Metadata's “ToS safe” is an author assertion, not established by these sources.

## 3. What Magpie should take — at most five
1. **adopt — bounded ACP stdout reassembly, not literal copied sizing.** Mechanism: abort pending requests and retire transport on overflow (`P:src/acp/jsonrpc.ts:80-86,124-130`; `P:src/acp/connection.ts:202-218`). Magpie currently appends/splits an uncapped `stdoutRemainder` (`M:src/runtime/acp-connection.ts:173-185`). Symptom prevented: memory growth from a missing newline/flood. Cost: low; use actual byte accounting and per-line boundaries, with a deliberate allowance for large image/tool frames; don't reproduce their string-length/pre-split approximation.
2. **defer — early-ack/poll/late-delivery machinery.** Mechanism: `P:src/provider.ts:448-488,923-947,1400-1411`. Symptom targeted: long MCP HTTP calls abandoned before human/delegation results arrive. Cost: high—new model-visible poll tool, result ownership/expiry/redelivery semantics and extra inference turns. First establish this failure on Magpie's 1.5.8 worker; the historical 180 s report is insufficient to impose that UX.
3. **skip for us — stream-json carrier staging and a 25 KB ACP rejection rule.** Mechanism: stream-only carrier branch and inline fallback (`P:src/provider.ts:1521-1556`; `P:src/sysprompt-agent.ts:51-75`). Symptom targeted there: old stream-json silent drops. Cost: filesystem lifecycle, agent/toolset changes and possible native-subagent suppression. Magpie already capability-gates native `_meta.antigravity.systemPrompt.append` at session creation (`M:src/runtime/worker.ts:657-663,733-764`); no inspected evidence justifies replacing it or limiting ACP to 25 KB.
4. **skip for us — zeroing ACP usage or copying pi's derived context-total formula.** Mechanism: exact parser plus gauge correction (`P:src/acp/connection.ts:558-577`; `P:src/acp/driver.ts:839-856`). Symptom targeted there: multi-inference billing aggregates inflating pi's context gauge. Cost: divergent/estimated accounting if transplanted. Magpie already consumes result usage and prefers unseen per-step measurements, with a fallback when absent (`M:src/runtime/worker.ts:1554-1558`; `M:src/usage/tracker.ts:134-150`); retain that distinction rather than infer “ACP has no usage.”
5. **skip for us — replacing cancellation with RC01 probe/kill-first semantics.** Current mechanism is notification → await prompt → teardown safety net (`P:src/acp/connection.ts:346-349`; `P:src/acp/driver.ts:586-627`). Symptom prevented: hung cancellation without needless server loss. Cost: no new machinery needed; Magpie already sends notification, cancels broker work and waits 1.5 s before retirement (`M:src/runtime/worker.ts:1618-1638`). Do not copy the historical id-bearing cancel probe; do not infer that their 10 s grace is optimal for us.

**Remaining verification:** raw historical captures and live 1.5.8 cancellation, usage, payload limits, tool parity and platform behavior were not exercised. Any live probe would require separate authorization; this pass supports the scoped code corrections above, not a general ACP conformance claim.
