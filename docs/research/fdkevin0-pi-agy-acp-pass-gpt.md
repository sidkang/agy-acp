## 2. What the extraction missed — observed behavior unless labeled otherwise

### Failure classification and host-visible rewriting
- Wire errors become `JsonRpcRemoteError` with message `method: rpc.message`, retaining numeric code/data separately (`U:src/jsonrpc.ts:19-32,251-258`). `mapError` inspects that **message**, not `rpc.code`/`rpc.data`; remote AUTH/TIMEOUT/context/rate/quota classification therefore depends on words, not a structured upstream status (`U:src/runtime.ts:1506-1540`).
- Existing `LlmError` bypasses classification. Process-exit handling explicitly installs TRANSPORT, even if the stderr-derived message names quota/auth (`U:src/runtime.ts:727-743`; stderr-tail construction `U:src/acp-process.ts:182-190`). A JSON-RPC deadline emits `no response within Nms` (`U:src/jsonrpc.ts:142-149`), which by itself misses the timeout regex and falls back to TRANSPORT; this is a code-derived consequence, not an executed test.
- The actual Pi boundary adds **`context_length_exceeded:`** for CONTEXT_WINDOW_EXCEEDED and **`quota exceeded:`** for QUOTA unless recognizable wording already exists ([`U:src/pi-stream.ts:83-99`](https://github.com/fdkevin0/pi-agy-acp/blob/19f4c26b09d78266f94fbd85740a6edc5ca3df00/src/pi-stream.ts#L83-L99)). Both finish failures and thrown errors take that path (`U:src/pi-stream.ts:295-325`); the final Pi message receives `errorMessage`/`stopReason`, not a separate LlmError code field.
- Read assertions explicitly target Pi's `isContextOverflow` and `isRetryableAssistantError` classifiers: synthetic overflow is recognized and quota is nonretryable (`U:tests/pi-stream.test.mjs:254-301`). This explains the trick; tests were **not run**, and the host classifier implementation remains unverified.
- Distinct termination paths: empty end_turn → EMPTY_RESPONSE; ending with outstanding relayed results → PROVIDER_ERROR; refusal → error/REFUSAL; cancelled → aborted/ABORTED; unknown stop → PROVIDER_ERROR (`U:src/conversation.ts:564-620`). max_tokens automatically continues up to three times by default (`U:src/conversation.ts:545-555`; `U:src/config.ts:61`). Retry and output-cap notices are suppressed/counted, not independently diagnosed as quota failures (`U:src/conversation.ts:269-298`).
- Host hooks see a synthetic `onResponse({status:200,headers:{}})` before the first non-initial-abort chunk, not an upstream HTTP status (`U:src/pi-stream.ts:200-209`). Tool-router exceptions instead become MCP `isError:true` content (`U:src/mcp-bridge.ts:394-419`), not a model failure taxonomy entry.

### Loopback authentication, authorization, and lifetime
- One runtime-owned listener binds **127.0.0.1 on an ephemeral port** (`U:src/mcp-bridge.ts:119-161`). Each ACP session opening generates a 16-byte random tenant path plus independent 24-byte random bearer secret, passed in MCP server headers (`U:src/runtime.ts:763-775`). Tenant-less/wrong-token requests get 401 **before** JSON parsing; constant-time equal-length comparison is used (`U:src/mcp-bridge.ts:220-243`; `U:src/runtime.ts:844-858`). No Host/Origin validation appears in the inspected request handler (`U:src/mcp-bridge.ts:204-278`); Magpie already has it (`M:src/mcp/http-server.ts:123-140`).
- Routing trusts registered tenant identity, not conversation metadata alone; optional ACP conversation metadata must match the tenant session (`U:src/runtime.ts:1387-1406`). Permission approval requires matching session/live turn and structured tool-call identity reported through session/update; conflicting/unknown identities are refused. Only an empty identity-less loading probe can use authenticated MCP initialize-handshake evidence, and only `allow_once` is selected (`U:src/runtime.ts:890-949`).
- Tenant registration/handshake evidence is revoked on session clear; new openings generate new credentials (`U:src/runtime.ts:861-866,1113-1122`). Authenticated DELETE merely returns 200: it does **not** revoke the tenant or close the listener (`U:src/mcp-bridge.ts:235-237`). Runtime reset closes sessions but retains the front/listener; disposal stops the front and closes the bridge (`U:src/runtime.ts:371-416`). Process exit clears affected sessions/tenants without directly closing the listener (`U:src/runtime.ts:727-744`).
- Bridge close destroys open SSE responses, clears handshake records, and closes all connections (`U:src/mcp-bridge.ts:168-180`). A disconnected call aborts its waiter (`U:src/mcp-bridge.ts:359-364`; `U:src/runtime.ts:1454-1473`), but that path alone does not cancel Pi execution or resolve/delete the original ParkedCall; turn abandonment separately settles calls (`U:src/conversation.ts:304-342`).

### Slow tools: liveness is not completion
- Headers flush before awaiting execution; every **15 seconds** by default a comment is written, plus token-correlated progress if requested. The final JSON-RPC result is one SSE `event: message`, then EOF (`U:src/mcp-bridge.ts:349-419,473-475`; `U:src/config.ts:59`). There is no work-percentage estimate; ticks only prove timer activity. The write path does not wait for backpressure/drain (`U:src/mcp-bridge.ts:367-392,473-475`).
- At **85 seconds**, absent a result/disconnect, awaitCall returns a textual “still running” result directing the agent to `mcp_pi_pi_await_result` with the original call id; subsequent awaits reuse the same result promise and timer race ([`U:src/runtime.ts:1407-1416,1441-1474`](https://github.com/fdkevin0/pi-agy-acp/blob/19f4c26b09d78266f94fbd85740a6edc5ca3df00/src/runtime.ts#L1407-L1474); `U:src/conversation.ts:639-647`). The **180-second agy MCP deadline/cache-refresh rationale is a source comment**, not independently verified vendor behavior (`U:src/config.ts:42`).
- While relayed, text/thought output is buffered up to **65,536 characters**; excess is dropped, and buffered output flushes when all relay IDs are re-awaited (`U:src/conversation.ts:137-138,207-253`). If the agent ends before retrieving relayed results, the host gets an error rather than a fabricated completed answer (`U:src/conversation.ts:564-572`).

### Session/state persistence and packaging
- Pi history is authoritative: reuse checks system digest and exact message-ID prefix; changed/pruned/compacted history rebuilds the ACP session (`U:src/runtime.ts:1015-1078`). Parked-turn resumption additionally requires unchanged model/effort (`U:src/runtime.ts:483-515`). Per-conversation keyed locking permits different sessions concurrently; capacity gate evicts oldest idle sessions, otherwise rejects RATE_LIMIT rather than queues (`U:src/runtime.ts:456-458,570-618`). Defaults: 16 sessions, 30-minute idle TTL, 60-second sweeper (`U:src/config.ts:56-57`; `U:src/runtime.ts:315-317,1477-1488`).
- No cross-process ACP session restore: startup deletes isolated conversation/brain/summary artifacts; per-session close cleans DB/WAL/SHM and brain files with path/symlink guards (`U:src/preflight.ts:217-255,285-303`; `U:src/runtime.ts:1091-1099`). Shared homes are explicitly unsupported without locking (`U:src/preflight.ts:285-288`; `U:docs/reference.md:118-122`). Catalog/models/efforts/tier persist to catalog.json (`U:src/runtime.ts:196-197`; `U:src/catalog.ts:209-263`); quota-display preference uses temp-write/rename (`U:src/config.ts:102-123`); quota snapshots are memory-only and coalesced, caching successes **and failures** for 120 seconds (`U:src/quota.ts:107-110,143-185`; `U:src/config.ts:62`).
- Replay has a 160,000-byte budget, preserves live input, drops older history with an omission marker, can truncate the latest oversized tool result, replaces historical images with `[image]`, and omits historical reasoning (`U:src/history.ts:29,139-145,172-184,226-324`). This is lossy reconstruction, not native session restoration.
- Auth isolation is not credential isolation: implementation seeds/refreshes from the newest nonempty source CLI token file unless the destination is already at least as new; destination is isolated `agy/antigravity-oauth-token`, best-effort chmod 0600 (`U:src/preflight.ts:175-213`); openSession re-syncs it (`U:src/runtime.ts:754`). The quota helper runs `agy -p /usage --output-format json` **without isolated-home flags** (`U:src/quota.ts:159-162`), unlike ACP launch. Same identity for a custom home therefore is not guaranteed by these arguments. No token files were accessed in this pass.
- Shipped artifact is MIT ESM **TypeScript source**, extension entry `index.ts`, no declared runtime `dependencies`, wildcard Pi peer packages; dev pins `~1.5.0`, Node floor 22.19.0 (`U:package.json:4-5,15-46`). README targets Pi 1.5.x / agy ≥1.4.12 (`U:README.md:11-16`); semver preflight enforces agy minimum but accepts non-semver/unknown diagnostics (`U:src/preflight.ts:128-151`). Windows discovery handles agy.exe / LOCALAPPDATA / semicolon PATH, other platforms use ~/.local/bin and PATH (`U:src/preflight.ts:64-118`). These branches are not proof of live OS compatibility.
- CI declares **Ubuntu only**, Node 22.19.0 and 24, typecheck/tests/pack-dry-run (`U:.github/workflows/ci.yml:16-40`); npm publishing is configured with provenance (`U:.github/workflows/release.yml:96-111`). No successful CI run, actual npm publication, or macOS/Windows execution was verified.
- Extra tool resilience: description compaction targets 1,350 bytes, full prose is supplied separately, and dynamic additions/changes use `pi_call_tool` (`U:src/mcp-bridge.ts:498-585`; `U:src/history.ts:111-120`). **Not a hard size guarantee:** the final compaction return is not size-checked and cannot shrink a large structural schema (`U:src/mcp-bridge.ts:574-585`).

## 3. What our plugin should take from this one — recommendations/inferences, maximum five

1. **adopt — SSE-first MCP replies with heartbeat/progress.** Mechanism: `U:src/mcp-bridge.ts:349-392,417-419`; current gap `M:src/mcp/http-server.ts:178-180`, `M:src/mcp/broker.ts:388-391`. Prevents a parked tool result from waiting headerless through approvals/builds. **Cost:** medium transport refactor plus disconnect/timer cleanup; preserve existing broker IDs, result validation, Host/Origin/token checks and finite deadlines. Does not prove agy's total deadline is solved.
2. **skip for us — wholesale prefix/error-taxonomy transplant.** Mechanism: `U:src/runtime.ts:1526-1537`, `U:src/pi-stream.ts:83-99,295-325`. `resource_exhausted` without 429 can become QUOTA, then acquire `quota exceeded:`; a transient limit would thus be presented as spent quota. `token limit` can become context overflow even when it names an output ceiling. Prevent the symptom of resting a healthy account or invoking the wrong context fallback: retain our semantic verdict/status and sanitized details (`M:src/runtime/diagnostics.ts:359-368,542-580,604-629`; `M:src/runtime/worker.ts:1068-1083,1133-1165`). **Cost:** low to reject the transplant; audit emitted wording as part of the routing contract, including raw suffixes. Prefixes can be appropriate for a true matched failure, not universally safe. Actual gateway Go source was not inspected; routing effects are the supplied integration constraint and documented plugin rationale, not a newly verified gateway implementation.
3. **defer — 85-second still-running/await-result protocol.** Mechanism: `U:src/runtime.ts:1407-1416,1441-1474`; `U:src/conversation.ts:639-647`. Intended symptom prevented: agy abandoning a slow tool despite activity. **Cost:** high, extra model tool rounds, relay buffering/loss, and dependence on the agent obeying an instruction. Magpie deliberately keeps authentic tool_use/tool_result ownership with no fake still-running completion (`M:src/mcp/broker.ts:9-11,388-391`); investigate a captured vendor total-deadline failure after SSE-first before changing that contract.
4. **adopt — targeted, bounded output-cap notice handling, not blind text deletion.** Mechanism: upstream normalized hold/drop/emit (`U:src/conversation.ts:28-75,269-298`), but `noticeHold` itself has no length cap (`U:src/conversation.ts:169-170,269-281`). Prevents vendor continuation instructions leaking into model answers while preserving quoted troubleshooting text. **Cost:** low–medium; reuse our bounded/provenance-aware notice approach (`M:src/runtime/turn-context.ts:266-277`; `M:src/runtime/diagnostics.ts:154-162`) rather than copy the unbounded hold or its unconditional chunk filter.
5. **defer — separate per-session bearer headers.** Mechanism: `U:src/runtime.ts:763-775,844-866`, `U:src/mcp-bridge.ts:220-233`; prevents a disclosed tenant URL alone granting tool access and revokes stale sessions. **Cost:** low–medium header plumbing/rotation; our existing 32-byte secret URL, constant-time matching, and Host/Origin checks already provide session-scoped authorization (`M:src/mcp/http-server.ts:14-17,64-74,106-140`). Add only if URL exposure is a concrete threat; do not weaken our existing origin checks while borrowing upstream auth.
